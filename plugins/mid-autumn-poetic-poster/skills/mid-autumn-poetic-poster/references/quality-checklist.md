# 质量检查清单

## 结构与审美

- [ ] 主题一眼可辨，主视觉只有一个。
- [ ] 有前景、中景、远景，或有明确的空间替代关系。
- [ ] 至少一块完整留白，标题和诗词有干净承载区。
- [ ] 局部丰富、大面积安静；没有所有元素平均铺满。
- [ ] 纸张轻微可见但不脏、不灰、不像旧报纸。
- [ ] 水墨水彩、柔边、低饱和与空间层次成立，没有廉价扁平或塑料感。

## 主题专项

- [ ] 月满/团圆的月亮柔和，不刺眼；归雁/望月的月亮小而淡。
- [ ] 月映或含河流的画面，月光随水面蜿蜒并被涟漪切碎，不是直线白柱。
- [ ] 桂花大小、虚实、成熟度和枝条方向有自然差异。
- [ ] 归雁中飞鸟是主体，数量适度，远近有层次。
- [ ] 灯火中暖光和人流成立，人物不出现可疑高清脸，灯笼不全是鲜红。
- [ ] 团圆中只有一个完整月饼和一个切开的月饼；蛋黄自然哑光，不发光。
- [ ] 共月或团圆的窗景有天然画框感，但没有多余物件抢主题。

## 文字与事实

- [ ] 标题字形可辨识，无错字；“盏”等易错字需逐字检查。
- [ ] 诗句与原文、作者、作品名一致；原创句不冒充古诗。
- [ ] 默认诗句没有逗号、句号或任何标点。
- [ ] 默认没有红色刻章。
- [ ] 文字没有压在复杂纹理上；必要时改为后期排版层。
- [ ] 用户要准确中文或可编辑文件时，已交付无字背景与独立文字层，且逐字校对。
- [ ] 诗句与画面节令相容；没有把元宵灯市诗当成中秋诗。

## 交付与系列

- [ ] 用户要成图时，实际提供图像；仅提供 Prompt 时没有宣称已生成成图。
- [ ] 用户要“只改一处”时，其他已认可内容保持一致。
- [ ] 同系列有一致的纸底、书法气质、文字层级和金箔强度，同时各主题主视觉可区分。
- [ ] 书签按 1:3 重新构图；如用于印刷，像素、出血、安全区与印厂要求相符。
- [ ] 参考图只提炼通用的光影和风格，没有复制独特构图或细节。

## 重试规则

若不合格，记录最主要的 1–3 个问题，做局部重试：

1. 先修主次和留白。
2. 再修主题专项错误（月亮、飞鸟、月光、静物等）。
3. 最后修文字与材质。

两轮仍不稳定时，采用无字背景 + 可编辑文字层的交付方式，并明确指出需要人工校对的内容。
