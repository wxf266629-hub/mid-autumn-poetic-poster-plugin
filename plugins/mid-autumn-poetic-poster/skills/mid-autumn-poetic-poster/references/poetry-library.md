## 选择规则

1. 用户指定诗句时先查原文与出处；若有异文，写明所用版本。
2. 用户没有指定诗句时，从主题库对应 ID 选一条。做系列时尽量不重复；若诗句数量不够，宁可留空待用户决定或明确标注原创短文案，也不拼接不同诗作成一首。
3. “灯火”强调市集时，P03 表达共赏月夜，但不直接写灯市；不从元宵诗词借“花市灯如昼”等句来冒充中秋。若用户希望诗句直接写灯火，提供原创文案并标注“原创文案”。
4. 古诗词的字形、作者和标题应独立于图像模型再次核对。终稿的诗句无标点；出处不必强制使用书名号。
