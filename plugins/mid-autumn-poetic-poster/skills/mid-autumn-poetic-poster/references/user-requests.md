# 用户常见问法与应答路由

从用户要解决的问题判断交付，不要求用户学习专门术语。用户明确指定的风格、主题、画幅、文字和参考图优先。

| 用户可能这样说 | 推断需求 | 交付与特别检查 |
|---|---|---|
| “做一张归雁” | 一张默认手机海报 | 飞鸟为主，远山淡月；生成成图并附核对后的诗句与出处 |
| “桂香，做成书签” | 50×150mm 书签 | 长窄构图，桂枝与留白；若需印刷读印刷规格 |
| “只要提示词，我自己去生成” | Prompt 包 | 正向 Prompt、负面约束、文字层清单、尺寸 |
| “给我八个主题，风格要像一套” | 系列 | 固定纸底、书法体系、边距、金箔强度；逐张改变主视觉与气氛 |
| “这张太满，素一点” | 局部修订 | 减少最低优先级元素，扩大完整留白，保留用户认可的主体 |
| “再惊艳一点” | 画面层次不足 | 改善主次、视线动线、冷暖对比与局部高光，避免无目的加物件 |
| “月亮别抢飞鸟” | 主次失衡 | 缩小、变淡、藏入薄云，并强化鸟群近远层次 |
| “月光像白柱子，改自然点” | 水面反光错误 | 用蜿蜒水面、涟漪、碎金反射修复 |
| “团圆要生活感，月饼少一点” | 静物密度过高 | 一个完整加一个切开的月饼，茶盏、桂枝适量；蛋黄哑光 |
| “共月从窗里往外看” | 窗景构图 | 开窗成画框；下方河岸商铺人流，上方小月桂枝，保持简洁 |
| “诗句不要标点，不要章” | 文字/装饰修订 | 清除所有诗句标点与红色刻章；逐字校对 |
| “把这句诗放上去” | 指定文字 | 先核对原文与出处；存疑时说明，不擅自署名 |
| “字不能错，还要可编辑” | 高可靠文字交付 | 无字背景 + 可编辑标题、诗句、出处；提供排版坐标或层级说明 |
| “参考这张图的感觉” | 风格参考 | 提取光影、留白、色彩、材质等通用规律；重新设计构图与细节 |
| “打印成书签” | 生产文件 | 成品尺寸、出血、安全边距、分辨率与印厂色彩要求分别确认 |

## 处理歧义与冲突

- “书签”默认成品尺寸 50×150mm；“手机海报”默认 1242×2208px。
- “给我一张”默认要成图；“给我提示词”默认不要成图。
- “不要文字”覆盖诗词默认规则，仍保留有意安排的留白。
- “归雁配巨大圆月”是用户明确偏好，可执行；简短提醒月亮可能弱化飞鸟主次，并优先用低亮度、侧置月亮兼容二者。
- “不要刻章”是硬要求；任何后续自动生成的红印都要删除。
- “和上一张一样”仅锁定本次可见且用户认可的特征；若上一张不可见，说明需要用户提供图或具体特征。
