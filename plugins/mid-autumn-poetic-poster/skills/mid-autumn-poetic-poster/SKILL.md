# 中秋古风诗意海报生成器

把一句简短主题（例如“做一张归雁”）扩展为统一系列的中秋竖版海报或书签。最高原则：**像一幅可以进入其中的中秋画卷**。追求第一眼有氛围、第二眼见主体、第三眼发现细节，而不是元素拼贴。

## 适用范围与触发条件

触发于以下请求：

- 生成、改写、扩展中秋主题的竖版海报、手机壁纸、节日视觉背景或书签
- 用户只给出“月满”“归雁”“共月”等主题词，希望自动补全画面、诗词和风格
- 用户要求中国古典、水墨水彩、宣纸、月光、桂花、灯火、诗意留白等统一视觉系列

不适用于：现代扁平插画、商业促销红金海报、与中秋无关的摄影海报，除非用户明确要求覆盖本 Skill 的默认美学。

## 默认输出与覆盖规则

- 手机海报：1242 × 2208 px，按竖版重新设计，不先做横图再裁切。
- 书签：50 × 150 mm，比例 1:3；若无具体尺寸，保持高而窄的长卷式构图。
- 默认输出：1 个主视觉、1–2 个辅助元素、少量氛围元素；保留至少一块完整呼吸区。
- 默认纸底：米白、暖白、淡杏、奶油色或淡宣纸色。
- 默认文字：主题大字 + 两句诗词 + 小号出处；诗句无标点，默认不加红色刻章。
- 用户明确给出的尺寸、主题、色调、文字或删减要求覆盖本 Skill 的默认值；未明确部分继续使用默认值。
- 冲突优先级：用户明确要求 ＞ 用户指定的主题核心视觉 ＞ 系列一致性 ＞ 默认装饰。若两项明确要求相互冲突，只问影响成品的那一个关键选择；若仅与默认值冲突，直接按用户要求执行并简短提示视觉取舍。

## 根据用户问法交付

先判断用户要的是**成图**、**提示词**、**可编辑排版方案**、**局部修改**还是**整套系列**。常见问法与路由见 [references/user-requests.md](references/user-requests.md)。

- “做一张归雁”“生成书签”：有图像工具时实际生成图；没有时交付完整可复制的 Prompt、文字方案和尺寸，不声称图片已生成。
- “只给我提示词”：交付正向 Prompt、负面约束、文字层内容和必要的出处，不额外生成图。
- “字要准确”“要印刷”：优先生成无字背景，再用可编辑文字层加入标题、诗句、出处；如工具不能做文字层，交付背景与排版规格并说明限制。
- “按上一张改一个地方”：只改被点名的元素，保留已获认可的构图、色彩和材质。
- “做八张一套”：先建立共用的系列参数，再按主题分别换主视觉与冷暖；不要把八张做成完全相同的月亮构图。

若用户明确只要概念或 Prompt，不调用图像生成。若用户要成图，使用可用的图像生成工具，并对实际结果做视觉检查。

## 核心视觉系统

### 风格

中国古典审美 + 水墨水彩 + 轻宣纸肌理 + 电影感光影 + 克制的暖金。画面应清雅、含蓄、空灵、温润、有东方空间感；边缘柔和、线条自然、层次真实但不要过度摄影写实。

### 构图

1. 先确定主视觉，再安排辅助元素；不要平均分配视觉重量。
2. 采用“局部丰富、大面积安静”的繁简分区。
3. 设计前景、中景、远景：前景可用窗框、桂枝、茶席；中景可用河流、桥、商铺、人群；远景可用山、塔、云、月。
4. 标题与诗词附近必须留出清晰底色；文字不能压在高密度纹理上。
5. 画面要有自然动线，但避免从月亮到底部的僵硬直线。

### 材质与色彩

- 宣纸只需极轻纤维、淡水彩晕染、少量纸本颗粒；第一眼应先看到画面，不是纸纹。
- 避免脏灰、过度泛黄、粗颗粒、重裂纹、旧报纸感。
- 低饱和墨色、灰蓝、烟青、茶褐、暖白为基础；暖场景可加入琥珀、赭棕、淡橙。
- 不使用廉价大红大金或满屏高饱和色。灯火可用暗红，但不可让所有灯笼鲜红。

### 金箔

金箔是光感，不是贴纸。只在云边、月缘、水面反光、山脊、桂花周围、灯火附近或极少量空气中出现。用微小金粉、碎金箔、极细金线、不规则金色颗粒表达；禁止大面积金底、满屏金粉、粗金描边、金属商业高光。

### 月亮与流水

- 月满、团圆可用较大的圆月；归雁、望月、思乡优先用小而淡、被薄云遮掩的月亮。
- 月亮不可在每张图都又大、又圆、又白、又强光；不能抢走归雁的主体。
- 月光倒影必须随河流蜿蜒，被涟漪打碎：中远处较集中，近景更零碎，像碎金波光。禁止一根笔直白色光柱。
- 山水用低饱和水墨、水彩、薄雾；远山更淡更冷，近山略深，可有少量树影或金线。

### 专项元素规则

- 桂花：花朵大小、成熟度、虚实不完全相同；淡黄、奶黄、金黄、琥珀黄少量混合。枝条细、略弯、不机械对称，花瓣自然散落。
- 飞鸟：归雁主题中飞鸟是主视觉，可用 2–4 只较清晰的大鸟加远处小鸟群，形成空间层次；不要让月亮成为视觉中心。
- 灯火：灯火主题以河流、商铺、灯笼、游船、桥、人流和暖光构成烟火气；人物以剪影和流动感为主，不生成高清脸。
- 生活静物：团圆默认一个完整月饼 + 一个切开的月饼展示横截面，蛋黄为自然哑光、磨砂的柔和橙黄，不像发光球、玻璃球或塑料球。茶盏、茶壶、木桌、桂枝适量即可。
- 窗景：共月、团圆、人间烟火优先考虑打开的中式窗作为天然画框；前景窗框/桂枝/茶盏，中景河流/商铺/人群/小船，远景山/塔/月/云。

## 文字与诗词

### 三层文字层级

1. 主题大字：毛笔书法，苍劲但可辨识，有自然飞白，不要过度狂草；冷画面用深灰蓝或墨色，暖画面用暖褐、金棕或深赭，避免死黑。
2. 诗词：主题旁或留白区，字号显著小于标题；默认两句、竖排或窄列排版。
3. 出处：更小字号，可竖排为“朝代 作者 作品名”，避免书名号等特殊符号造成生成错误。

诗词优先从 [references/poetry-library.md](references/poetry-library.md) 选择，并按其中链接核对原文、作者、作品名和异文。库外诗词也要核对可靠文本；不能把原创仿古句冒充古诗。若找不到契合主题的真实诗句，可交付明确标注的原创文案且不署古人名字；不要拿元宵诗冒充中秋诗。不要让诗句暗示画面中并不存在的节令或活动。

可靠成品默认采用两阶段文字流程：先生成预留文字空间的**无字背景**，再把标题、诗句、出处加入可编辑文字层，逐字校对。若环境没有排版工具而用户要完整带字成图，可让图像工具尝试绘字并逐字检查；出错时回退到无字背景、准确文字内容和可编辑排版说明，明确指出还需排版。文字是交付的一部分，不可用“留白”代替用户明确要的诗句。

默认诗句**不使用逗号、句号或任何标点**，例如：

但愿人长久
千里共婵娟

默认无红色刻章；只有用户明确要求时才加入，并单独校对印章文字。

## 用户输入解析

从短输入中提取：

1. 主题词：优先匹配主题库；未匹配时提炼情绪与主物件。
2. 画幅：手机海报 / 书签 / 用户自定义尺寸。
3. 覆盖项：色调、是否要窗景、是否要诗词、指定诗句、是否允许印章、文字方向、简洁或繁复程度。
4. 输出约束：需要纯图、需要可编辑文字层、需要生成提示词、需要多张系列等。
5. 用户口语中的隐含指令：例如“素一点”表示减少辅助物和金箔；“再惊艳些”优先强化构图、光影和层次；“生活感”优先茶席、窗景与人的痕迹；“和上一张一样”表示锁定已认可的系列参数。

若只有主题词，不追问一长串问题，直接采用主题库默认方案。用户给出指定诗句时，先核对后再排版；指定句并非可靠古诗时，说明并提供真实诗句或原创文案的选择。只有缺失信息会实质改变交付且无法合理推断时，才问一个简短问题。

## Prompt 组装

按以下顺序组装生成提示词，避免遗漏关键约束：

`画幅与用途 → 主题与情绪 → 主视觉 → 前中远景 → 色彩与光影 → 宣纸/水墨/水彩材质 → 金箔位置 → 留白与文字区 → 文字内容与层级 → 负面约束`

先使用 [references/theme-library.md](references/theme-library.md) 选择主题参数，再使用 [references/prompt-template.md](references/prompt-template.md) 生成最终提示词。整套系列和印刷书签额外读取 [references/series-and-print.md](references/series-and-print.md)。中文描述优先；如图像模型对英文更稳定，可提供中英双语关键词，但不要让翻译改变主题层级。

## 自动纠错、检查与重试

生成前做结构检查：主视觉是否唯一、画面是否有呼吸区、前中远景是否合理、主题月亮大小是否匹配、文字是否有清晰承载区、诗词是否已核实。

生成后按 [references/quality-checklist.md](references/quality-checklist.md) 检查。发现问题时只修改对应变量，不推翻全部风格：

- 元素过多：删除最低优先级的辅助元素，扩大留白。
- 月亮抢戏：缩小、降亮度、加薄云或移至远景。
- 月光成直线：改为蜿蜒水面、涟漪切碎的局部反光。
- 金箔过量：只保留 1–3 个光感区域，降低密度与饱和度。
- 桂花塑料感：增加大小、虚实、成熟度差异，减少对称。
- 文字错字或标点：去掉生成式文字，改为后期排版；诗句逐字对照原文。
- 出现红章：删除；除非用户明确要求。
- 画面太摄影或太扁平：恢复水墨水彩、宣纸、柔边和低饱和空间层次。

同一问题最多做 2 轮定向重试；第二轮仍失败时，输出问题说明、已保留的正确部分和建议的人工排版/局部重绘方案。不会在未确认图像工具能力或用户意图时无限重试。

## 主题示例

至少支持：月满、桂香、望月、月映、灯火、归雁、团圆、共月。完整映射、示例诗词与默认画面参数见 [references/theme-library.md](references/theme-library.md)。

## 完成标准

成品必须同时满足：主题一眼可辨、主次明确、至少一处完整留白、材质轻而不脏、金箔克制、文字层级清楚、古诗词真实且无默认标点、无默认红章、没有明显 AI 塑料感。不要抄袭参考图的具体构图、人物、纹样或独特细节，只提炼可复用的审美原则。
